## 2. 受け入れ条件・ユースケース

共通の決まり:
- 日付は日本時間（Asia/Tokyo）。週は月曜に始まり日曜に終わる。記録には、端末の時刻（`recorded_at`）と、そこからサーバーが出した日本時間の日付（`local_date`）を持つ
- 記録・セット・スタンプ・コメントは、端末で作った UUID を ID に持つ。同じ ID が2回届いても、作られるのは1件（F-30）
- 自分の記録は**削除だけ**できる（編集はない。間違えたら消して入れ直す）
- 他の人の記録は、**同じグループのメンバーにだけ**見せる（どの API でも、毎回メンバーかを確かめる）

### 2.1 F-01 ユーザー登録・ログイン

| UC | 流れ | 受け入れ条件 |
|----|------|--------------|
| UC-01 登録 | メールアドレス・パスワード・表示名を入れて登録する | 登録すると、そのままログイン状態になり、今日タブに移る。**招待リンクから来た人は、招待画面（S-03）に戻る**（リンクの値は登録・ログインの画面をまたいで端末に一時保存する）。登録時に確認メールは送らない（[design.md 2章](./design.md)）。同じメールアドレスでの再登録は「すでに使われています」と出る |
| UC-02 ログイン | メールアドレス・パスワードを入れる | 成功すると Cookie セッションが発行される。間違いのときは、メールアドレスとパスワードのどちらが違うかを言わず、同じ文言を出す |
| UC-03 ログアウト | 自分タブの設定から押す | セッションが無効になり、ログイン画面に移る |
| — | ログインしていないとき | ログイン画面・新規登録・招待画面（S-03。グループ名と人数だけ見える）以外は開けず、ログイン画面へ移る。ログインしたら元の画面に戻る |

パスワードの条件は認証ライブラリ（better-auth）の既定に従う。決めたら tech-stack.md に書く（未決）。

### 2.2 F-02 グループ

既定: **1人が入れるグループは1つだけ**（判断ログ 決定16）。最大5人。

| UC | 流れ | 受け入れ条件 |
|----|------|--------------|
| UC-04 作る | グループ名を入れて作る | 作った人が最初のメンバーになる。すでにグループに入っているときは作れない（409） |
| UC-05 招待する | メンバーが「招待リンクを作る」を押す | 推測できない値（128ビット以上の乱数）のリンクができる。**有効期限は7日**（既定）。リンクの文字列は作った直後の1回だけ画面に出し、DB にはハッシュだけを保存する |
| UC-06 参加する | リンクを開き、ログインして「参加する」を押す | 参加するとグループ名と今のメンバーが見える。期限切れは 410、5人で満員なら 409、すでに別のグループにいるなら 409（「今のグループから出てからにしてください」と出す） |
| UC-07 出る | 自分タブの設定から押す | 確認のあとにメンバーから外れる。自分の記録は残るが、仲間には見えなくなる。最後の1人が出たら、グループは空のまま残る（削除はしない） |

境目の確認: 4人のグループに同時に2人が参加しようとしたとき、通るのは1人だけで5人を超えない（参加の処理は、人数の数え直しと追加を1つのトランザクションにする）。

### 2.3 F-03 筋トレの記録（セットごと1タップ）

判断ログ 決定18。種目の選び方は 決定15。

| UC | 流れ | 受け入れ条件 |
|----|------|--------------|
| UC-08 記録する | 今日タブの「はじめる」→ セットごとに「できた」を押す。**前回の筋トレの記録があれば、前回と同じ種目が同じ順で「今日のメニュー」に並んでいる**（外す・足す・並べ替えもできる）。前回がなければ、「種目を選ぶ」から始める | 前回の**同じ種目・同じセット番号**の重量・回数が最初から入っている。前回の同じ番号が無いときは、前回の最後のセットの値が入る。前回がまったく無いときは、前回なし（空）で、重量と回数を入れてから押す |
| — | 値を直すとき | 回数と重量に「＋/−」ボタンがある（回数は±1、重量は±2.5kg）。数字を直接打つこともできる。**1セット目で値を変えたら、2セット目以降はその値が入る** |
| — | 押したとき | **1秒以内**に画面へ反映する（記録の保存は非機能要件 5.2 の目標）。電波がなくても反映する（F-30） |
| — | 種目の選び方 | 部位つきの一覧（約30種目）から選ぶ。無い種目は、名前と部位を1つ選んで自分用に追加できる。追加した種目は、種目の一覧には自分にだけ出る。ただし記録した足跡には種目名がそのまま出るので、仲間にも何をしたかは伝わる。同じ名前の種目は重ねて作れない（大文字小文字は区別しない。共通の種目と同じ名前も不可） |
| — | 間違えたとき | 押したセットは、その場で削除できる（取り消し）。削除は電波があるときだけ |
| — | 1回の運動の区切り | 種目を選んで最初のセットを押したときに、その日の筋トレの記録（`records` の1行）ができる。同じ日に2回目の運動をするなら、新しい記録になる（既定: 前の記録の最後のセットから**3時間以上**あいていたら別の記録） |

境目の確認: 重量 0kg（自重の種目）を許す。重量は 0〜500kg の 0.5 刻み、回数は 1〜999 回。範囲の外は 400 を返す。

### 2.4 F-04 ランの記録（手入力）

| UC | 流れ | 受け入れ条件 |
|----|------|--------------|
| UC-09 記録する | 距離（km）と時間（分・秒）を入れて保存する | 距離は 0.1〜200km、時間は 1 分〜24 時間。ペース（分/km）は画面が計算して見せる（DB には持たない） |

### 2.5 F-05 ゴースト（前回の自分）

| 項目 | 受け入れ条件 |
|------|--------------|
| 前回とは | **同じ種目の直近の記録**（既定）。1セットごとに「前回の同じセット番号」と並べる |
| 比べ方 | 重量が同じなら回数で、違えば「重量×回数」で比べる（決定14）。例: 前回 40kg×10 → 今回 40kg×11 は回数で上回る。今回 45kg×9（405）は前回 40kg×10（400）を上回る |
| 結果の言い方 | 上回った（「前回超え +N」）／同じ（「前回と おなじ」）／下回った（「ちゃんと 記録したよ。むりしない日もOK」）。**「負け」とは言わない・色を悪く見せない** |
| 表示 | 記録中に、前回の値と今回の値を並べたバーを出す |

### 2.6 F-06 記録直後の祝福

| 項目 | 受け入れ条件 |
|------|--------------|
| 出し方 | 「できた」を押した直後に、結果シートを**0.8秒**出す。タップで飛ばせる。動きを減らす設定（`prefers-reduced-motion`）のときは動かさない |
| 自己ベスト | **その種目で、過去最大の「重量×回数」を超えた**セットに「ベスト」の札を付ける（既定）。初めて記録する種目の最初のセットは、札を付けない（比べる相手がいない） |

### 2.7 F-07 継続の表示・F-08 今日は休む

| UC | 受け入れ条件 |
|----|--------------|
| UC-10 今週の7マス | 月曜〜日曜の7マスを出す。記録した日＝色つき、休んだ日＝淡い色（欠けに見せない）、まだ来ていない日＝薄い丸。**連続日数は出さない・持たない**。月曜 0:00（日本時間）にまっさらから始まる |
| UC-11 おかえり | **記録のない日が2日以上続いた**あとの最初の記録で、「おかえり」を祝う（最後の記録の日と今日の日付の差が3日以上。月曜に記録して木曜に開いたとき）。**休みは記録に数える**ので、休みの日をはさんだ人には出さない。あいた日数は責めずに一言添える程度にとどめる |
| UC-12 責めない一言 | 前日の記録の有無・あいた日数に応じて、ホームの一言を出し分ける。「また 0 から」「途切れた」のような言葉は使わない |
| UC-13 休む | ホームの「今日は休む」を押すと、今日の休みが記録される。**休みは1日1件**（2回押しても1件）。仲間の足跡に「おやすみ」と出て、仲間は休み用のスタンプを返せる。その日に筋トレやランを記録しても、休みは残る（マスは「記録した」の色が優先） |

境目の確認: 日曜 23:59 と月曜 0:00 の記録が、別の週になる。日本時間の深夜0時前後の記録が前後の日にずれない（リスク #3）。

### 2.8 F-09 仲間の足跡・週の合計・F-10 スタンプ・コメント

| UC | 受け入れ条件 |
|----|--------------|
| UC-14 足跡を見る | 仲間タブに、今週の同じグループの記録を新しい順に出す（種類・時刻・種目名の要約）。段階的に読み込む（1回に20件・もっと見るで続き）。他グループの記録は出ない |
| UC-15 週の合計 | 今週のグループ合計（記録した人数・筋トレの総重量・ランの総距離）を出す。**順位・連続日数は出さない**。自分が休んでも、仲間の数字は減らない |
| UC-16 スタンプ | 記録にスタンプを付ける。固定の数種類（既定）から選ぶ。**同じ人が同じ記録に同じスタンプを2回付けられない**（2回目は成功扱いで1件のまま）。休みの記録には休み用のスタンプを使う。自分で外せる |
| UC-17 コメント | 定型文（固定の数種類。既定）か自由入力（**50字まで**）を付ける。51字目は 400。**自分のコメントは削除できる**。他の人のコメントは削除できない |

### 2.9 F-11 初回の体験

| 項目 | 受け入れ条件 |
|------|--------------|
| 60秒 | 登録後、説明を読まなくても**60秒以内**に最初の1セットを記録できる（画面の数は「今日 → 種目を選ぶ → できた」の3つ以内） |
| お試しゴースト | 前回がない種目では、お試しの前回値（固定。例: ベンチプレス 20kg×10）を灰色の「お試し」の札つきで並べる。**お試しの値は記録として保存しない**。削る順②で、お試しゴーストを削る |

### 2.10 F-12 筋肉ヒートマップ・F-13 動画・F-14 GPX・F-15 地図

| 機能 | 受け入れ条件 |
|------|--------------|
| F-12 | 自分タブに体の図を出し、**今週（月曜〜今日）に記録したセットの種目の部位**を色の濃さで示す。濃さは、その部位のセット数が多いほど濃く、段階は3段階（既定）。部位の一覧は database-design.md の `body_part`。削る順⑤で、部位の一覧表示にする |
| F-13 | 筋トレの記録に、画面の中で**2秒だけ**撮影して付ける（**1記録に1本**。既定）。720p・MP4/H.264 を優先し、できないときは撮影できた形式のまま保存する。大きさの上限は 10MB（既定。2秒の720pは約1〜3MB の見込み。技術検証 #1 で実機を測る）。仲間に見えるのは**その週の終わり（日曜 24:00 日本時間）まで**、本人はずっと見られる（URL の発行で制御）。削る順③で写真にする |
| F-14 | GPX ファイルを選ぶと、距離・時間・ルートを読み取って記録にする。壊れた XML・線が0本・ファイルが大きすぎる（5MB 超。既定）ときは、記録を作らず理由を出す。ルートの点は間引いて保存する（上限 3,000 点。既定） |
| F-15 | ランの記録の詳細に、ルートを地図に出す。削る順④で、距離・ペースの数字だけにする |

### 2.11 F-30 オフライン記録

技術は [tech-stack.md](./tech-stack.md#オフライン記録f-30)、表示は [screen-design.md](./screen-design.md#送信待ちの表示f-30) を正とする。受け入れ条件は次のとおり。

| 条件 | 内容 |
|------|------|
| 範囲 | 記録の**作成**（筋トレのセット・ランの手入力・休み）。編集・削除・スタンプ・コメント・動画・GPX は電波があるときだけ |
| 電波なしで押したとき | 画面へ即座に反映し、帯に「送信待ち N件」を出す。再読み込みしても送信待ちが残る |
| 戻ったとき | 同じ順番で送り直す。サーバーの記録は**ちょうど1件ずつ**（二重保存も消失もない） |
| ログイン切れ | 送信待ちを捨てず、ログインし直したら送る |
