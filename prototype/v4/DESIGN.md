# プロトタイプ v4 デザインの数値（参考スクショからの分解）

v2.1・v3 は「テーマ」から画面を作ったため、指定していない部分が既定値に戻り、AI が作ったような見た目になった。v4 では、本人が選んだ実在アプリの画面を数値に分解し、その数値だけで組む。ここに無い値は使わない。

- 数値は、スクショを幅390pxの画面に換算した推定値（実測ではない）
- 参考アプリのロゴ・キャラクター・絵は使わない。借りるのは寸法と構成だけ

## 1. 画面ごとのお手本

| FitLog の画面・部品 | お手本 | 本人の評価 |
|---|---|---|
| 今日（日付の帯・種目の2列タイル・右下の丸ボタン） | ティールの筋トレ記録アプリ | 「見やすさで言ったら抜群。結構好き」 |
| 下のタブ | UMAWALK | 「アイコンと相まって見やすい」 |
| 自分（週の記録カード） | UMAWALK の記録画面 | 同上 |
| 筋肉ヒートマップ | GoGym（明るい背景に置き換え） | 「ヒートマップは1枚目」 |
| 休みの日 | ドット絵の寝ているお手本 | 「寝てるポーズだと癒される」 |
| ランの結果 | よくあるランアプリ | 「よくあるアプリのやつで見やすい」 |
| 仲間（記録の行） | STEPN（丸いアバター＋名前＋日時） | 「アイコンがある感じが SNS の要素もあっていい」 |

黒背景は使わない（本人決定）。

## 5. 動き

- 動きは1本だけ: 「できた」でタイルの回数が前回超えなら橙に変わり、`+1` が上に浮いて消える（0.6秒）
- 休みの日のドット絵: 2コマで寝息（胸が1px上下・「z」が浮く）。`prefers-reduced-motion` では止める

## 6. 機能の載せ方（FitLog の決定との対応）

| FitLog の機能 | どこに・どう |
|---|---|
| 今週の7マス（F-07） | 上の日付の帯そのもの。記録した日＝点、休んだ日＝小さな月のアイコン。連続日数は出さない |
| 週・月・年（F-22） | 右上の D/W/M。D＝今日の種目タイル、W＝週のまとめ、M＝月のカレンダー |
| 前回値入りの1タップ記録・ゴースト（F-03・F-05） | タイルの数字＝前回の値。タップで記録画面。記録画面は前回の値が最初から入り「できた」1タップ。前回との差を橙で |
| 今日は休む（F-08） | 右下の2つ目の丸ボタン「休む」。押すと今日のタイルの代わりにドット絵の寝ているカード |
| 仲間の足跡・スタンプ（F-09・F-10） | 仲間タブ。STEPN 型の行（アバター・名前・日時・大きな数字）＋スタンプ |
| 筋肉ヒートマップ（F-12） | 自分タブの1枚目のカード。GoGym 型（人体2つ＋部位バー＋凡例） |
| ランの記録・地図（F-04・F-14・F-15） | ランの結果画面（日時の丸い札・距離・3列・ルートの絵） |
| グラフ（F-27） | 自分タブの週の記録カード（UMAWALK 型の棒グラフ） |
| オフライン記録（F-30） | 電波がないときは記録画面の上に「端末に保存しました。つながったら送ります」の細い帯 |
