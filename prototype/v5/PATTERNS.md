# プロトタイプ v5 ── デザインの型ごと違う4パターン

本人（2026-10-26）: 「色の比較ではなく、パターンの違うデザインの比較を求めていた。最初に作ったふにゃふにゃ感の強いふざけたデザインとか。スクショのようなポップな感じも好き。再三言っている Duolingo のデザイン。デザインとともにボタン構成や雰囲気、そのアプリの強みを変えて比較させてほしい」「ドットとヒートマップのデザインが合っていなくて違和感がある」

## 全パターン共通の約束
- **1つのパターンの中では、絵柄を1つにそろえる**。ヒートマップの人体・休みの日の絵・アイコン・ボタンが同じ線の太さ・同じ塗り方であること（v4 の違和感の原因は、写実的なにじみの人体とドット絵の混在）
- ホーム・記録・仲間・自分の**画面構成とボタンの置き方そのもの**をパターンごとに変える（色だけ変えるのは禁止）
- 機能はそろえる: 今週の7日（連続日数は出さない）／前回値入りの1タップ記録（ゴースト）／今日は休む／仲間のスタンプ／筋肉ヒートマップ（今週鍛えた部位）
- データ: 今日 10/29（木）。今週 月=胸の日・火=休み・水=背中の日・木=今日。脚の日: スクワット 前回60kg×10回×3／ルーマニアンデッドリフト 50kg×12回×3／レッグプレス 100kg×12回×3／カーフレイズ 40kg×15回×3。部位: 胸3・肩3・腕4・背中3セット・脚0。仲間: ケン4日・ミホ2日・ユウタ3日・サキ1日（休み2）
- 明るい背景（黒背景は使わない）。参考アプリのロゴ・キャラ・絵はそのまま使わず、自分で描く
- 1パターン1ファイル。画面はハッシュで切替: `#today`・`#record`・`#rest`・`#friends`・`#me`。PCでは 390×844 の枠を中央に。押せる所は44px以上
- 外部読み込みは版を固定: Tailwind `@tailwindcss/browser@4.3.3`、Google Fonts、lucide `1.61.0`（絵柄に合わなければアイコンは自作 SVG でよい）
- 装飾は「そのパターンの絵柄に必要なもの」だけ。グラデーションの光彩・ガラス風・絵文字は使わない

## P1 Duolingo 型「次の1つだけ」（`p1-duo.html`）
**強み**: 迷わない。今やることが常に1つだけ光っていて、押すと次が光る。学習アプリの「道」の作法で、筋トレのメニューを一歩ずつ進める
- 絵柄: 平らな塗り・線なし・丸み。**ボタンは「厚み」**: 同じ色相の濃い色で下に4pxの帯（`box-shadow: 0 4px 0 濃い色`）、押すと4px沈む。角丸16px
- 色: 地 `#FFFFFF`、主（進む）緑 `#58A700` 系ではなく自分の緑 `#4CB82F`／濃い `#3A8F22`、完了の金 `#FFC800`／濃い `#E0A800`、仲間の青 `#2AA8F0`／濃い `#1A86C4`、休みの紫 `#A57BF0`／濃い `#7E57C9`、未着手の灰 `#E5E5E5`／濃い `#C9C9C9`、文字 `#4B4B4B`
- 書体: Nunito 800（見出し・数字）＋ M PLUS Rounded 1c 700（日本語）。見出しは大きく太く
- `#today`: 上に横一列のステータス（今週の日数「2」＋小さな7つの丸、仲間の数）。その下が**縦の「道」**: 4種目が直径72pxの丸い厚みボタンで、左右にジグザグに並ぶ（済み＝金＋チェック、今＝緑で上下にゆっくり弾み「はじめる」の吹き出し、まだ＝灰＋鍵ではなく番号）。道の途中に「休む」の紫の丸（月のアイコン）。下に固定の大きな緑の厚みボタン「はじめる」
- `#record`: 上に進み具合のバー（緑・高さ16px・角丸8px）と × 。中央に「スクワット」と大きな「60kg × 10回」、前回の自分（灰の小さなカード）。下に固定の緑の厚みボタン「できた」。押すと画面下からシートが上がる（緑の地に「前回超え！ +1回」＋「つぎへ」ボタン）＝Duolingo の正解シートの作法
- `#rest`: 道の上の紫の丸が「おやすみ」になり、中央に**同じ平らな塗りの絵**（丸い頭の人が布団で寝ている。線なし・3〜4色）
- `#friends`: 仲間のカード（厚みのある白カード・枠線2px `#E5E5E5`・下に4pxの厚み）。丸いアバター・名前・今週の日数・厚みボタンのスタンプ
- `#me`: **ヒートマップも平らな塗り・線なしの人体**（前後。部位を3段階の色: 灰→薄い緑→濃い緑）。下に部位ごとの厚みのある横バー

## P2 ポップ・イラスト型「埋めて集める」（`p2-pop.html`）
**強み**: 体を「マップ」として塗り広げる収集の楽しさ。本人のスクショ（タウンマップ・カラフルどおり）の絵柄
- 絵柄: **黒い太線3px＋平らなビビッドな塗り**、背景に網点（ドットのハーフトーン）、ステッカー風のラベル（白地・黒線・角丸の札）、ギザギザのバッジ（歯車のような円）。影は黒の真下ずらし（`4px 4px 0 #1A1A1A` ではなく `0 4px 0 #1A1A1A`）
- 色: 地 `#FFFFFF`＋網点 `#F7B7CF`/`#9BE0D3`、桃 `#FF4F8B`、青緑 `#1FB5A0`、黄 `#FFD23F`、紫 `#6B4BD8`、線と文字 `#1A1A1A`
- 書体: Mochiy Pop One（見出し・ボタン）＋ Zen Maru Gothic 700（本文）
- `#today`: 画面いっぱいの**「からだマップ」**: 角の丸い島の中に、部位がエリア（胸・背中・肩・腕・お腹・脚）として道でつながる。今週鍛えたエリアは色が付き、まだのエリアは灰色に「？？？」の札。今日の「脚」エリアに黄色い吹き出し「ここ！」。右上にステッカー型の「ずかん」（スタンプ帳）と数字。下にギザギザの丸い大ボタン「出発！」と小さめの「休む」
- `#record`: 太線のカードに大きなコミック体の「60kg×10回」、前回超えで「ドドン！ +1」のような文字が太線つきで跳ねる。±はステッカー風の丸ボタン
- `#rest`: 同じ太線の絵で、人がハンモックか布団で寝ている（網点の夜空・月）
- `#friends`: ステッカーが貼られた掲示板（5人の顔のステッカー・吹き出しのコメント・スタンプはギザギザのバッジ）
- `#me`: **ヒートマップも太線の平らな人体**（前後）。部位を桃・黄・青緑の3段階で塗り、凡例は札
- ※ 絵の量が多い。工数が最も大きい

## P3 ドット絵型「ゴーストとたたかう」（`p3-pixel.html`）
**強み**: 前回の自分（ゴースト）との対戦が RPG のバトルになる。休みの日は宿屋で眠る。すべてが同じドット絵の世界
- 絵柄: **すべてドット**。1マス4px、`shape-rendering: crispEdges`、`image-rendering: pixelated`。枠は2段のドットの線（白の内線＋濃い外線）のウィンドウ。角丸なし
- 色（16色以内のパレット）: 空 `#9BD4F5`、草 `#5DBB63`、地面 `#C9A66B`、ウィンドウ地 `#FFFFFF`・枠 `#2B2D42`、勇者の服 `#E84B3C`、ゴースト `#B9C3FF`、金 `#FFD23F`、文字 `#2B2D42`
- 書体: DotGothic16（全部）
- `#today`: 上半分が**ドット絵の場面**（ジムの前の草原に主人公が立つ。今週の7日は空に7つの星、記録した日は金）。下半分が RPG のコマンドウィンドウ: 「▶ スクワット　前回 60kg×10」「ルーマニアン…」…、最後に「やすむ」。カーソル（▶）で選ぶ
- `#record`: **バトル画面**: 右に「前回のじぶん」（半透明のゴースト・HP の代わりに「10回」）、左に主人公。下のウィンドウに「60kg × 10回」と ±、コマンド「できた！」。押すと「11回！ 前回のじぶんを こえた！」のメッセージが1文字ずつ出る
- `#rest`: 宿屋の部屋でベッドに寝る主人公（寝息の2コマ・z）。「やどやで やすんだ。からだが かいふくした」
- `#friends`: パーティーのウィンドウ（5人のドットの顔・今週の日数・スタンプはドットのアイコン）
- `#me`: **ヒートマップもドット**（前後の人体を 4px の格子で描き、部位のマスを 3段階の色で塗る）。ステータス画面風に「むね 3 / かた 3 / …」

## P4 ふにゃふにゃ型「押すのが楽しい」（`p4-funya.html`）
**強み**: 触ると全部がぷるんと揺れる。ゆるい文言で、休むことも笑って肯定する。v1 の「ふにゃっと」「全部ふざける」の方向を突き詰める
- 絵柄: **手描き風のゆがんだ線**（SVG の `feTurbulence`＋`feDisplacementMap` で線をわずかに揺らす、または `border-radius: 58% 42% 55% 45% / 45% 55% 45% 55%` のような不定形）。太めの線2.5px `#2B2D42`、塗りはクレヨン風（`feTurbulence` で少しかすれ）。要素がわずかに傾く（-2〜2deg）
- 色: 地 `#FFF6E0`（ただしクリーム＋コーラルの組み合わせは使わない）、主 `#3D7BFF`（青）、黄 `#FFD84D`、ミント `#6EDCB4`、桃 `#FF8FB1`、文字 `#2B2D42`
- 書体: Mochiy Pop One ではなく RocknRoll One（見出し）＋ Zen Maru Gothic（本文）
- 動き: 押すと `scale(.9)→1.08→1` のばねで揺れる（ゼリー）。主ボタンは常にゆっくり呼吸（scale 1→1.03）
- `#today`: 画面中央に**巨大なゼリーのボタン**「きょうも ちょっとだけ やる？」（直径220pxの不定形）。上に7つのゆがんだ丸（今週）。下に小さく「やすむ〜」「メニューを見る」。メニューはボタンを押すと下からふにゃっと出る
- `#record`: 数字が不定形のゼリーの中に入っていて、± を押すと数字ごとぷるんと揺れる。「できた」で画面全体が一瞬ふくらみ、「やるじゃん！ +1」
- `#rest`: 同じ手描き線で、ソファでだらっと寝る人（クレヨン塗り）。「休むのも筋トレのうち〜」
- `#friends`: 手描きの付箋（傾いたメモ）に5人。スタンプは手描きの丸
- `#me`: **ヒートマップも手描き線＋クレヨン塗りの人体**（前後）。部位をミント→黄→桃の3段階
